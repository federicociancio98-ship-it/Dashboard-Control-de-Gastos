Configuración necesaria antes de subirlo

En este archivo hay dos valores que tenés que editar antes de deployar:

CONFIG.clientId: Client ID de la App Registration de Azure/Entra.

CONFIG.excelPath: ruta del archivo en tu OneDrive, por ejemplo /Apps/Dashboard/Gastos 2026.xlsx.

El dashboard no usa backend. El navegador se autentica con Microsoft, lee las tablas del Excel y escribe cambios mediante Microsoft Graph. Vercel solo sirve este HTML estático.
